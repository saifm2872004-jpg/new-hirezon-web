NEW HORIZON — MULTI-PAGE WEBSITE

النسخة متعددة الصفحات مع الحفاظ على تصميم وألوان وصور القالب الأصلي.

الصفحات:
index.html — الرئيسية
about.html — من نحن + الرؤية والرسالة والأهداف
products.html — المنتجات والحلول
services.html — التوريد والفحص + تصنيع OEM + الزيارات التجارية
shipping.html — الشحن والخدمات اللوجستية
projects.html — نماذج الأعمال
contact.html — التواصل وطلب عرض سعر

زر اللغة: عربي / English على جميع الصفحات مع حفظ الاختيار محليًا.
كل الروابط الداخلية في القوائم والفوتر والأزرار تنقلك الآن بين صفحات فعلية.

طريقة التشغيل: افتح index.html أو ارفع جميع الملفات إلى مجلد public_html على الاستضافة.
احتفظ بمجلد data بجانب ملفات HTML دون تغيير مساراته.

ملاحظات للنشر: تحقق من بيانات الشركة ووسائل الاتصال وأي صور/أسماء مشاريع قبل الإطلاق. نموذج عرض السعر يُجهز رسالة واتساب ولا يحفظ بيانات على الخادم.
